# AI Usage Log
**Date:** 12 November 2026

**Project Title:** Student Record Management System in C

**AI Tool Used:** ChatGPT (OpenAI)

## 1. Purpose of AI Usage

ChatGPT was used to assist in improving the Student Record Management System, debugging errors, explaining program logic, and designing an AI-Assisted Academic Advisor feature.

## 2. Prompts Used

**Prompt 1:**  
"Check my Student Record Management System C code and identify errors."

**Prompt 2:**  
"Explain what is wrong with my CGPA calculation logic."

**Prompt 3:**  
"Add a small AI-Assisted Academic Advisor feature to the C program using CGPA-based recommendations without connecting to an AI API."

**Prompt 4:**  
"Write the complete C program incorporating all the original requirements and the AI-Assisted Academic Advisor."

**Prompt 5:**  
"Add comments to the complete C program to explain its functions and logic."

## 3. Useful Ideas Obtained

- Improved input validation to prevent invalid user entries.
- Used functions to organize the program into smaller, manageable sections.
- Calculated CGPA using the average of available SGPA values.
- Used `if-else` statements to classify students into four academic performance categories.
- Used structure swapping to sort complete student records by SAP ID and name.
- Added an academic advisor that provides recommendations based on CGPA.

## 4. AI-Assisted Academic Advisor Suggestions

| CGPA Range | Category | Recommendation |
|---|---|---|
| 9.00–10.00 | Excellent Performance | Maintain current study pattern. |
| 7.50–8.99 | Good Performance | Continue working consistently. |
| 6.00–7.49 | Needs Improvement | Focus on subjects with lower SGPA. |
| Below 6.00 | Requires Immediate Attention | Improve study routine and seek academic guidance. |

## 5. Verification and Modifications

The AI-generated suggestions and code were reviewed before implementation. The recommendations were modified to suit the college project requirements. The academic advice was implemented using predefined conditions in C rather than a live AI connection.

## 6. Final Outcome

The Student Record Management System was improved with input validation, CGPA calculation, sorting, searching, deletion, year-wise average CGPA calculation, and an AI-Assisted Academic Advisor.

**AI Integration:** No external AI API or internet connection is required to run the program. ChatGPT was used only as a development and design assistance tool.

**Conclusion:** AI assistance helped improve the program's structure, understand programming concepts, identify errors, and develop the academic recommendation feature. The final implementation was reviewed and adapted for the project.
